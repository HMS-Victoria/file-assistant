## 强烈建议的演示脚本

为了让截图有说服力，建议直接使用仓库自带的样例文件（`tests/sample_files/`）：

1. 拖入 `会议通知.docx`，输入"帮我在这个文件里找'会议'"，截图查询结果。
2. 拖入 `报销表.xlsx`，输入"金额的总和是多少"，截图本机统计结果。
3. 拖入 `会议通知.docx`，输入"把'张三'替换成'李四'"，截图确认弹窗。
4. 确认后截图"生成新文件"的提示与 `.file_assistant_backups/` 里的备份。

这四步能完整展示"AI 出计划 → 本地校验 → 预览确认 → 永不覆盖"这条主线。

## 放置方式

把图片直接放进本目录，然后在根 `README.md` 的「系统架构」或「运行方法」章节按下面的写法引用：

```markdown
![修改确认弹窗](docs/images/04-confirm-dialog.png)
```

## 为什么这里只有清单没有图

界面截图需要在真实的 Windows 桌面上运行程序获取，且容易连带暴露本地路径、用户名或真实文档内容，
必须由仓库作者本人确认后提供。自动生成或合成的界面图会误导阅读者，因此不在此处放置占位图片。
