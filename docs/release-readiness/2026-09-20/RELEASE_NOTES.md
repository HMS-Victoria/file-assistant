# 文件小助手 0.1.0-rc1 — 本地发布候选说明

状态：便携构建及设置功能已实现；最终候选资产以 `VERIFICATION.md` 记录为准。**包已生成，实际环境验收待完成。** 尚未上传 GitHub Release。

## 用户将获得什么

- `FileAssistant-0.1.0-rc1-windows-x64.zip`：完整 Windows x64 程序包，包含 Python、Qt 和文档处理运行库。必须完整解压，双击 `FileAssistant/文件小助手.exe`；保留 `_internal`。
- 同目录 `SHA256SUMS`：校验 ZIP 是否完整。
- `FileAssistant-0.1.0-rc1-source.zip`：本批源码快照，面向维护人员，不是普通用户程序包。
- 包内 `使用说明.txt`：首次运行、离线查询、设置、升级、卸载及文档保护说明。

## 此版本新增

- 设置窗口：填写本人 DeepSeek 密钥、模型、测试连接、保存或取消。
- 密钥采用 Windows 当前账户加密并存于固定用户目录；不再自动加载 `.env`。旧版用户需重新填写，原 `.env` 不会删除。
- 明确的本地查找和 Excel 求和/平均值/最大值/最小值/筛选入口，无需 AI 账号或联网。
- 配置与目录写入失败时给出可操作的中文提示。
- 保留修改前预览、取消、备份、另存新文件、重开验证和恢复原件的流程。

## 条件与限制

适用 Windows 10/11 x64。开发机验证为 Windows 11，Windows 10 与无 Python 的干净电脑尚待验收。
本地查询无需 Office/Python 或账号；AI 模式需要网络、本人 DeepSeek 密钥、服务余额及所选模型的使用权限，可能产生费用。
PDF 只读且无 OCR。Word 替换可能改变段内格式。AI 主处理等待服务时可能短暂无响应；设置连接测试在后台执行。
未提供安装向导、自动更新或数字签名。尚未将候选包称为“下载即用”。

项目自身未声明许可证；第三方许可文本随包提供。作者需在公开分发前确定项目许可与第三方对应源码安排。当前源码 ZIP 是本项目快照，不是全部第三方对应源码。

## 发布之后必须补做

获得发布授权后，使用实际提交重建，上传完整程序 ZIP 和 SHA256SUMS；从公开链接重新下载核对 SHA-256，并记录新电脑及本人密钥验收结果。
