文件小助手 0.1.0-rc1 便携版

适用：Windows 10（1809 或更新版本）/11，64 位（x64）。这是预发布测试包，尚未完成新电脑人工验收。

一、打开
1. 将 FileAssistant-0.1.0-rc1-windows-x64.zip 完整解压到自己的文件夹。
2. 打开 FileAssistant 文件夹，双击“文件小助手.exe”。
3. 请保留同目录的 _internal 文件夹，不要只复制 exe，也不要直接在压缩包内运行。
无需另装 Python、Office 或开发工具。程序尚未签名。

二、不填密钥也能使用
1. 拖入 .docx、.xlsx 或有文字层的 .pdf。
2. 选择“本地查找文字”，输入要找的原文，点“开始处理”。
3. Excel 统计：选择“Excel 求和”等选项，填写第一行的列名，例如“金额”；工作表名称留空使用第一个工作表，再点“开始处理”。
4. Excel 筛选：填写列名，输入要筛选的值，再开始。
以上明确标有“无需联网”的功能不会调用 AI。自然语言请求请使用“AI 帮我处理”。

三、首次使用 AI
1. 使用自己的 DeepSeek 开放平台账户申请服务密钥，并确保该账户有可用服务额度。
2. 点击主窗口“设置”，粘贴服务密钥；模型名称默认 deepseek-chat，也可填写自己账户支持的模型。
3. 点击“测试连接”。成功后点“保存设置”。测试会发送简短文字，可能产生少量费用，不读取用户文件。
4. 选择“AI 帮我处理”，输入要求。涉及修改时先核对预览，再点“确认修改”；点“取消”不会生成文件或备份。
5. 连接失败时按中文提示检查网络、密钥、余额或模型名称。退出设置仍可用本地功能。

四、配置和隐私
设置保存在当前用户的 %LOCALAPPDATA%\FileAssistant\settings.json。
密钥由 Windows 当前用户加密。不要将设置文件复制给别人；更换电脑或 Windows 账户后请重新填写。
清空密钥并保存即可停用 AI。关闭设置时点“取消”会丢弃本次输入。
程序不再自动读取 .env 或启动目录中的配置，旧版用户需要在设置中重新填写。
自然语言理解会向 DeepSeek 发送用户输入和文件类型。总结、问答还会发送最多 12,000 字符的文件内容。

五、文档保护与限制
原文件保持不变。修改前必须确认，确认后先备份再生成“原名_AI修改”新文件，并重新打开验证。
备份在原文件旁的 .file_assistant_backups 文件夹。可将所需备份复制出来并另取新名字，勿覆盖现有文件。
PDF 只支持读取，不生成“修改版 PDF”。扫描图片型 PDF 没有文字识别。
Word 文字替换可能改变段内字体等细节，请核对新文件排版。
目录无法写入时，请把文件复制到自己有写入权限的文件夹重试；请勿删除原件。
AI 处理沿用现有同步流程，等待网络返回时主窗口可能短暂无响应。设置中的连接测试在后台执行。

六、升级与卸载
退出旧版，把新 ZIP 解压到一个新目录。用户设置和原文件旁的备份不会随程序目录变化。
删除解压目录即可移除程序；如还要清除配置，可删除自己的 %LOCALAPPDATA%\FileAssistant 目录。
请自行保留文档及其备份。
